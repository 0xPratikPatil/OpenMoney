## Creating a Portfolio

1. Navigate to the **Dashboard**
2. Click **New Portfolio**
3. Enter a name and optional description
4. Add positions with ticker, quantity, entry price, and date

## Adding Positions

Each position tracks:
- **Ticker** — The security symbol
- **Quantity** — Number of shares or units
- **Average Entry Price** — Cost basis per unit
- **Date Opened** — When you entered the position

OpenMoney automatically calculates:
- Current market value (real-time price × quantity)
- Unrealized P&L and P&L percentage
- Position allocation within the portfolio

## Risk Analytics

Visit the **Risk** tab for any portfolio to see:
- Value at Risk (VaR) at 95% and 99% confidence
- Sharpe and Sortino ratios
- Maximum drawdown with peak-to-trough dates
- Beta vs S&P 500
- Correlation matrix of holdings
- Position-level risk contribution
